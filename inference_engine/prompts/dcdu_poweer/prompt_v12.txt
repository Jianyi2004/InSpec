说明:
**本示例有两个关键学习目的：**
**目的1：认识电源保护装置的外观特征，避免误识别**
本示例展示了两种电源保护装置的真实外观，请仔细学习其特征：
- **左侧：空气开关** - 独立的白色矩形模块，有开关把手，正面印有品牌和额定电流标识（如 `C100A`）
- **右侧：熔断器** - 独立的圆柱形灰白色器件，外壳上印有型号和额定电流标识（如 `63A`）
**重要警示**：DCDU 设备本体、接线端子排、线缆标签、配电箱内的其他设备（如接触器、继电器等）**都不是电源保护装置**，不要误识别。只有符合上述外观特征的空气开关或熔断器才是电源保护装置。
**目的2：严格对应装置本体与额定电流数值，禁止误读**
在读取额定电流时，**必须确保数值位于该装置本体上**，不得误读相邻装置或其他设备上的数值：
- **空气开关**：额定电流数值印在该空气开关本体正面，只能读取该模块上的数值
- **熔断器**：额定电流数值印在该熔断器本体外壳上，只能读取该圆柱体上的数值
- **严格规则**：一个装置 → 只对应一个数值；数值位置不明确、可能属于相邻装置或其他设备 → 视为不可读取，不得使用
**总结**：通过本示例学习电源保护装置的准确外观，避免将其他设备误识别为保护装置；同时学习装置—数值的严格一一对应关系，避免将其他装置或设备上的参数误用。

## 检查流程（严格按顺序执行）
### 步骤0：识别包含电源保护装置的图片
首先逐张判断每张图片是否包含电源保护装置（空气开关或熔断器）。参考示例图片中的外观特征：
- **空气开关**：**独立安装在配电箱/导轨上**的矩形模块，通常有开关把手，正面印有额定电流标识
- **熔断器**：**独立安装**的圆柱形器件，外壳上印有额定电流标识
**关键判断标准 - 必须是独立安装的装置**：
- ✓ **是电源保护装置**：独立安装在配电箱/导轨上，与DCDU设备分离的空气开关或熔断器
- ✗ **不是电源保护装置**：
  - DCDU设备本体的电源输出端（黑色外壳，集成在设备上的输出断路器/开关）
  - DCDU设备的电源输入、输出端口
  - 线缆标签、设备铭牌等辅助信息
**特别警示**：DCDU设备输出端虽然有黑色矩形模块和额定电流标识，但这些是**设备集成的输出开关**，不是独立的电源保护装置。参考示例2的反例说明。
在 analysis 中说明每张图片是否包含电源保护装置，并标注哪些图片仅为辅助图片。**如果图片展示的是DCDU设备输出端，必须明确标注为不包含电源保护装置。**
**辅助图片的作用**：
某些图片虽然不直接包含电源保护装置，但可能显示 DCDU 设备的输入端或输出端，这些位置通常有：线缆标签
标签信息可以帮助你在其他图片中定位对应的电源保护装置。在步骤1中应充分利用这些辅助信息进行识别。
**注意**：本步骤仅用于初步筛选有效图片。
### 步骤1：识别 DCDU 电源保护装置
按优先级识别：
1. **用户框选或箭头标注**的保护装置
2. **保护装置上或附近的标签、标识、铭牌**
3. **接入装置的线缆标签**：查看连接到保护装置的线缆上是否有标签
4. **跨图片关联识别**：利用辅助图片中 DCDU 设备输入/输出端的信息（线缆标签）来定位对应的电源保护装置
**识别结果**：
- 若能明确识别出 DCDU 电源保护装置，仅对该装置进行后续检查
- 若无法识别，则对所有电源保护装置都要进行判断
必须在 analysis 中说明识别到哪个是 DCDU 电源保护装置及依据，或者说明无法识别的原因。
### 步骤2：检查额定电流容量
**重要原则 - 严禁猜测数值：**
如果电源保护装置上的额定电流数值**无法清晰看清**（模糊、被遮挡、拍摄过远、光线不足等），说明用户拍摄质量有问题，**必须判 FAIL**。不得基于部分可见字符、装置型号、或任何其他信息进行猜测或推断数值。只有数值完全清晰可读时，才能用于判断。
**强制读数验证流程（防止误读相邻装置数值）：**
在读取任何额定电流数值前，必须在 analysis 中按以下顺序执行验证：
1. **先定位装置**：用可见特征描述该装置（优先使用标签、标识、线缆标注等）
2. **再描述数值位置**：说明额定电流数值在该装置的哪个部位（如"该空气开关正面中央印有"、"该熔断器外壳上标注"）
3. **验证空间对应**：确认数值确实印在该装置本体上，而非相邻装置或其他设备上
4. **最后读取数值**：只有完成上述验证后，才能读取并使用该数值进行判断
**禁止行为**：不得跳过验证步骤直接读数；不得使用归属不明确的数值；不得使用"第几个"等序数词定位装置。
**若已明确识别 DCDU 电源保护装置：** 
只对这些识别出来的DCDU电源保护装置进行判断。必须执行上述读数验证流程：先描述装置位置 → 描述数值位置 → 验证空间对应 → 读取数值。额定电流清晰可见且 ≥ 32A 为合格，< 32A 或数值模糊/被遮挡/拍摄过远均判 FAIL。
**若无法明确识别 DCDU 电源保护装置：** 
对所有拍全的且已接入电源线的保护装置逐一检查。每个装置都必须在 analysis 中执行完整的读数验证流程：(1) 描述装置位置，(2) 描述数值位置，(3) 验证空间对应，(4) 读取数值。所有装置必须同时满足：额定电流标识清晰可见且均 ≥ 32A，才可判合格。任意一个装置的额定电流标识模糊/不可读，或额定电流 < 32A，或无法确认数值归属，均判 FAIL。
### 步骤3：检查电源线安装规范（仅在明显违规时判FAIL）
**接入空气开关时：**
- 电源线接入空气开关处应使用冷压端子，若清晰可见未使用冷压端子 → FAIL
- 接入处不得用绝缘胶带缠绕，若明确看到被胶带包裹 → FAIL
**接入熔断器时：**
- OT端子末端应有热缩套管或绝缘胶带保护，若明确裸露无保护 → FAIL
- 螺丝应紧固，若明显松动或空接 → FAIL
**注意**：仅在清晰可见明显违规时才判FAIL，若图片未拍清或无法确认，不得判FAIL。
