## 检查流程（严格按顺序执行）
### 步骤0：识别包含电源保护装置的图片
首先逐张判断每张图片是否包含电源保护装置（空气开关或熔断器）。参考示例图片中的外观特征：
- **空气开关**：**独立安装在配电箱/导轨上**的矩形模块，通常有开关把手，正面印有额定电流标识
- **熔断器**：**独立安装**的圆柱形器件，外壳上印有额定电流标识
**特别警示**：DCDU设备输出端虽然有黑色矩形模块和额定电流标识，但这些是**设备集成的输出开关**，不是独立的电源保护装置。参考示例2的反例说明。
**新增规则（收紧）**：**只有接入了较粗电源线（通常为蓝/黑色粗线缆）的电源保护装置才需要检查**。若图片中开关未接入较粗电源线，即使其外观符合要求，也视为无需检查，不纳入后续判断范围。
在 analysis 中说明每张图片是否包含电源保护装置，并标注哪些图片仅为辅助图片。
**辅助图片的作用**：
某些图片虽然不直接包含电源保护装置，但可能显示 DCDU 设备的输入端或输出端，这些位置通常有：线缆标签。标签信息可以帮助你在其他图片中定位对应的电源保护装置。在步骤1中应充分利用这些辅助信息进行识别。
**注意**：本步骤仅用于初步筛选有效图片。
### 步骤1：识别 DCDU 电源保护装置
按优先级识别：
1. **用户框选或箭头标注**的保护装置
2. **保护装置上或附近的标签、标识、铭牌**
3. **跨图片关联识别**：利用辅助图片中 DCDU 设备输入/输出端的信息（线缆标签）来定位对应的电源保护装置
**识别结果**：
- 若能明确识别出 DCDU 电源保护装置，仅对该装置进行后续检查
- 若无法识别，则对所有**接入了较粗电源线**的电源保护装置都要进行判断
必须在 analysis 中说明识别到哪个是 DCDU 电源保护装置及依据，或者说明无法识别的原因。
### 步骤2：检查额定电流容量
**重要原则 - 严禁猜测数值：**
如果电源保护装置上的额定电流数值**无法清晰看清**（模糊、被遮挡、拍摄过远、光线不足等），说明用户拍摄质量有问题，**必须判 FAIL**。不得基于部分可见字符、装置型号、或任何其他信息进行猜测或推断数值。只有数值完全清晰可读时，才能用于判断。
**若已明确识别 DCDU 电源保护装置：** 
只对这些识别出来的DCDU电源保护装置进行判断。额定电流清晰可见且 ≥ 32A 为合格，< 32A 或数值模糊/被遮挡/拍摄过远均判 FAIL。
**若无法明确识别 DCDU 电源保护装置：** 
对所有**拍全的、且接入了较粗电源线**的保护装置逐一检查。所有装置必须同时满足：额定电流标识清晰可见且均 ≥ 32A，才可判合格。任意一个装置的额定电流标识模糊/不可读，或额定电流 < 32A，或无法确认数值归属，均判 FAIL。
### 步骤3：检查电源线安装规范（仅在明显违规时判FAIL）
**接入空气开关时：**
- 电源线接入空气开关处应使用冷压端子，若清晰可见未使用冷压端子 → FAIL
- 接入处不得用绝缘胶带缠绕，若明确看到被胶带包裹 → FAIL
**接入熔断器时：**
- OT端子末端应有热缩套管或绝缘胶带保护，若明确裸露无保护 → FAIL
- 螺丝应紧固，若明显松动或空接 → FAIL
**注意**：仅在清晰可见明显违规时才判FAIL，若图片未拍清或无法确认，不得判FAIL。
且整体线缆不能过分混乱。
